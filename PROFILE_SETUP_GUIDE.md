## 🎨 Badge Customization

### Profile Stats Badges
The profile uses several badge services:

1. **Profile Views Counter**: `komarev.com/ghpvc/`
2. **GitHub Stats**: `github-readme-stats.vercel.app`
3. **Streak Stats**: `github-readme-streak-stats.herokuapp.com`
4. **Shields.io**: Custom badges for skills and contact

### Color Themes
You can customize the color themes for the stats widgets:
- Default themes: `default`, `dark`, `radical`, `merko`, `gruvbox`, `tokyonight`
- To change: replace `theme=default` with your preferred theme

## 🔧 Advanced Customization

The profile is modular. You can add new sections like:

- **Patents**

### Technology Badges
Add new technology badges using this format:
```markdown
![TechName](https://img.shields.io/badge/TechName-HexColor?style=flat-square&logo=logoname&logoColor=white)
```

Use [Simple Icons](https://simpleicons.org/) to find logo names and colors.

### GitHub Activity Integration
The profile includes a placeholder for WakaTime integration. To set this up:
1. Install the WakaTime extension in your IDE
2. Set up the WakaTime GitHub Action
3. The weekly coding stats will automatically update

The profile uses these widgets with customizable parameters:


2. **Top Languages Card**:
   ```markdown
   ![Top Languages](https://github-readme-stats.vercel.app/api/top-langs/?username=LaneChen77&layout=compact&theme=default&hide_border=true)
   ```

3. **Streak Stats**:
   ```markdown
   ![GitHub Streak](https://github-readme-streak-stats.herokuapp.com/?user=LaneChen77&theme=default&hide_border=true)
   ```

### Privacy Settings
- Set `count_private=true` to include private repository contributions
- Use `hide=issues,contribs` to hide specific stats if needed
